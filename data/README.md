# data/

Không lưu file dữ liệu lớn ở đây trong git. Mỗi file tải về phải có một dòng trong `registry.csv`.
Thứ tự ưu tiên tải (xem docs/02): (1) track bảo tồn/alignment đã tính sẵn của cộng đồng (rẻ) → (2) bộ gene tham chiếu chào mào/họ Chào mào → (3) bộ gene ngoài nhóm (gà, cá sấu, rùa) → (4) chỉ khi cần mới tải nhiều bộ gene để tự align.
